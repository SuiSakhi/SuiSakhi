# ARCH-CAT-009 Candidate View and Semantic Truth Governance

**Version:** 1.0 REVIEW DRAFT
**Status:** Review before visual reconstruction

## Decision

A generated reconstruction is a candidate design view, not verified design
truth. One observed view may correspond to multiple valid hidden-view designs.

## Principles

1. Observed semantics describe only visibly supported design features.
2. Hidden-view features remain unknown, inferred or generated.
3. Multiple candidate views may be valid for the same observed input.
4. Generated candidates require human review and explicit approval.
5. View-specific semantics must not be forced equal across Front and Back.
6. Preserved cross-view semantics include garment type, silhouette, sleeve,
   cuff, compatible collar structure and visual proportion when supported.
7. Closure, yoke, darts, panels, embroidery and other hidden constructions may
   be view-specific.
8. Catalogue semantics never contain physical measurements or customer data.
9. Fixture ground truth remains distinct from generated candidate metadata.
10. Approved candidates do not overwrite immutable observed source assets.
